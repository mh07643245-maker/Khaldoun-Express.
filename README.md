# خلدون إكسبريس – تطبيق Android

هذا المشروع هو تطبيق Android أصلي مبني باستخدام Kotlin وJetpack Compose. تم الإبقاء على ملفات وخصائص التطبيق الأصلية، مع تعديل طريقة توقيع نسخة Debug وإضافة مسار بناء تلقائي ينتج ملف APK قابلًا للتثبيت.

## المميزات الموجودة في المشروع

- لوحة تحكم وإدارة شركات الشحن.
- إدارة الشحنات والعملاء والبحث.
- قاعدة بيانات محلية Room.
- استيراد ملفات Excel وإدخال البيانات بالنسخ واللصق.
- قراءة بيانات الصور OCR بالعربية والإنجليزية.
- مسح الباركود بالكاميرا.
- التقارير وتصدير PDF العربي.
- النسخ الاحتياطي والإعدادات.
- إدارة المخزون.

> هذه قائمة بالوظائف الموجودة في الكود؛ يجب اختبار كل وظيفة على جهاز حقيقي قبل الاعتماد التشغيلي.

## إنشاء ملف APK تلقائيًا (الطريقة الأسهل)

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع **كل محتويات هذا المجلد** إلى المستودع، وليس ملف ZIP نفسه.
3. افتح تبويب **Actions** في المستودع.
4. اختر **Build installable Khaldoun Express APK**.
5. اضغط **Run workflow** ثم **Run workflow** مرة أخرى.
6. انتظر حتى تنتهي المهمة بعلامة خضراء.
7. افتح نتيجة التشغيل، وانزل إلى **Artifacts**.
8. نزّل `Khaldoun-Express-APK` واستخرج الملف المضغوط؛ ستجد `Khaldoun-Express.apk`.

## تثبيت APK على هاتف Android

1. انقل `Khaldoun-Express.apk` إلى الهاتف.
2. افتح الملف من تطبيق **ملفاتي** أو **Files**.
3. إذا طلب الهاتف السماح بالتثبيت من هذا المصدر، فعّل **السماح بتثبيت التطبيقات من هذا المصدر** لتطبيق الملفات الذي تستخدمه.
4. ارجع إلى ملف APK واضغط **تثبيت**.
5. بعد انتهاء التثبيت افتح تطبيق **خلدون إكسبريس**.

هذه نسخة Debug موقعة تلقائيًا بمفتاح Android Debug القياسي، وهي مناسبة للتجربة والتثبيت. لا تنشرها كتحديث رسمي للعملاء؛ للنشر النهائي يلزم إعداد مفتاح Release خاص وآمن والاحتفاظ به، واستخدام نفس المفتاح في كل تحديث لاحق.

## البناء محليًا من Android Studio

- افتح المجلد في Android Studio حديث.
- استخدم JDK 21.
- اسمح لـ Android Studio بتنزيل مكونات Gradle وAndroid SDK المطلوبة.
- من قائمة **Build > Build Bundle(s) / APK(s) > Build APK(s)** أنشئ APK Debug.
- الناتج المتوقع: `app/build/outputs/apk/debug/app-debug.apk`.

## ملاحظات مهمة

- بيانات التطبيق مخزنة محليًا باستخدام Room بحسب تنفيذ المشروع؛ لا تفترض وجود مزامنة بين عدة هواتف.
- لا تضع كلمات مرور أو مفاتيح خاصة داخل المستودع.
- نجاح إنشاء APK في GitHub Actions لا يغني عن تثبيته وتجربة الشاشات والاستيراد والباركود والتقارير على الهاتف.
